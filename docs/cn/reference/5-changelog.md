## v1.1.0 (2024-06-15) ✨ 企业级功能版本

### 🚀 新增功能
1. **企业级部署支持**
   - 新增 PostgreSQL 会话存储引擎，支持高并发访问
   - 新增 Kubernetes 部署 Helm Chart
   - 新增分布式缓存支持（Redis）
   - 新增多节点集群部署支持

2. **安全与权限**
   - 新增 OAuth2 / LDAP / SAML 统一身份认证
   - 新增 RBAC 基于角色的权限控制
   - 新增操作审计日志功能，所有操作可追溯
   - 新增敏感信息加密存储功能

3. **扩展能力**
   - 新增 MCP（模型上下文协议）客户端工具
   - 新增平台适配器扩展机制，支持快速接入新的消息平台
   - 新增技能市场 API，支持企业私有技能市场部署
   - 新增自定义工具热加载功能，不需要重启即可加载新工具

4. **功能增强**
   - 新增批量处理命令 `hermes batch`，支持批量处理文档、提问等
   - 新增会话导出功能，支持导出为 Markdown / PDF / HTML 格式
   - 新增消息通知功能，支持 Webhook / 邮件 / 企业微信等通知方式
   - 新增配置热重载功能，修改配置不需要重启服务

### ⚡ 性能优化
1. 上下文压缩算法优化，压缩速度提升 300%，压缩率提升 20%
2. 提示词缓存命中率提升到 85%，平均响应速度提升 40%
3. 会话存储性能优化，查询速度提升 200%，内存占用降低 30%
4. 工具调用异步化，多工具并行调用速度提升 500%

### 🐛 修复问题
1. 修复 Windows WSL2 环境下路径兼容性问题
2. 修复长会话上下文丢失问题
3. 修复工具调用参数解析错误问题

## 升级指南

### 小版本升级（比如 1.0.0 → 1.0.1）
```bash
# 停止服务
pkill -f hermes

# 升级版本
pip install --upgrade hermes-agent

# 重启服务
hermes gateway --daemon
```

### 次版本升级（比如 1.0.x → 1.1.0）
```bash
# 1. 备份配置和数据
cp -r ~/.hermes ~/.hermes.backup

# 2. 停止服务
pkill -f hermes

# 3. 升级版本
pip install --upgrade hermes-agent

# 4. 执行数据库迁移
hermes migrate

# 5. 验证配置
hermes config show

# 6. 重启服务
hermes gateway --daemon
```

### 回滚版本
如果升级后出现问题，可以回滚到之前的版本：
```bash
pip install hermes-agent==1.0.0
# 恢复备份的数据
cp -r ~/.hermes.backup ~/.hermes
```

## ❓ 常见问题
### Q：升级会丢失我的会话数据和配置吗？
A：不会，升级过程会自动迁移数据和配置，升级前建议备份 `~/.hermes` 目录。

### Q：不同版本之间的配置兼容吗？
A：次版本和修订版本都是向下兼容的，主版本升级可能需要调整配置，升级时会自动迁移或者给出提示。

### Q：在哪里可以看到最新的开发进展？
A：可以访问 GitHub 仓库的 [Releases](https://github.com/a1pha3/hermes-agent/releases) 页面查看最新版本和变更内容，或者查看 [CHANGELOG.md](https://github.com/a1pha3/hermes-agent/blob/main/CHANGELOG.md) 文件。
