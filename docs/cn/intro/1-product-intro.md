## 什么是 Hermes Agent

Hermes Agent 是一款开源的多功能 AI 智能体开发框架，支持多平台部署、原生工具调用、可插拔技能扩展，是面向开发者和企业的通用 AI 助手落地解决方案。

**为什么需要它？**  
传统 AI 助手大多是 SaaS 服务，数据不可控、扩展性差，无法满足定制化需求。Hermes Agent 提供了一套完全自主可控的 AI 智能体解决方案，你可以根据需求自由扩展功能、部署到任意平台。

---

## 核心功能特点

### 1. 多平台支持
- 本地 CLI 交互：支持终端下交互式使用
- 消息网关：支持 Telegram、Discord、Slack、WhatsApp、HomeAssistant、Signal 等主流消息平台
- IDE 集成：支持 VS Code、Zed、JetBrains 等 IDE 的 ACP（编辑器适配协议）适配器

**为什么需要它？**  
你无需为不同使用场景重复开发 AI 助手，同一套 Hermes Agent 配置可以同时运行在终端、消息平台和 IDE 中，降低开发和维护成本。

---

### 2. 强大的工具系统
- 内置数十种内置工具：文件操作、网络搜索、浏览器自动化、代码执行、子代理调度、MCP（模型上下文协议）客户端等
- 工具权限控制：支持按平台启用/禁用工具
- 危险操作审批机制：自动检测高危命令并请求用户确认

**为什么需要它？**  
纯大语言模型本身不具备和真实世界交互的能力，工具系统让 AI 助手能够实际执行操作，而权限控制和审批机制保障了操作的安全性。

---

### 3. 灵活的技能系统
- 技能即插即用：支持动态加载技能扩展功能
- 技能市场：内置技能市场，支持搜索、安装、管理技能
- 自定义技能开发：支持用户开发自定义技能满足个性化需求

**为什么需要它？**  
通用 AI 助手无法满足所有细分场景需求，技能系统让你可以按需扩展功能，无需修改核心代码。

---

### 4. 高性能优化
- 上下文自动压缩：智能压缩上下文，降低 Token（令牌）消耗
- 提示词缓存：支持 Anthropic 提示词缓存，大幅降低成本和响应时间
- 多模型支持：支持 Anthropic、OpenAI 等主流大语言模型（LLM）

**为什么需要它？**  
长上下文的 Token 成本很高，优化特性可以降低 30%-70% 的使用成本，同时提升响应速度。

---

### 5. 多配置集（Profile）隔离
- 支持多 Profile 配置：不同配置集完全隔离，互不影响
- 独立的配置、密钥、会话存储：每个 Profile 拥有独立的运行环境

**为什么需要它？**  
你可以用不同 Profile 分别处理工作、个人、测试等不同场景，避免配置和数据互相干扰。

---

### 6. 会话管理
- SQLite 会话存储：支持 FTS5 全文搜索
- 会话历史持久化：所有对话历史自动保存
- 会话轨迹导出：支持导出对话轨迹用于调试和分析

**为什么需要它？**  
会话持久化让你可以随时回溯历史对话，全文搜索可以快速找到历史信息，轨迹导出方便调试和优化 AI 行为。

## 适用场景

1. **个人开发者助手**：本地 CLI 交互，辅助开发、调试、查文档
2. **团队协作助手**：部署到消息平台，作为团队内部 AI 助手
3. **企业级服务**：作为企业内部 AI 服务，集成到内部系统
4. **自定义 AI 应用**：基于 Hermes Agent 框架二次开发，打造专属 AI 应用

## ❓ 常见问题
### Q：Hermes Agent 需要付费吗？
A：完全开源免费，你可以自由使用，不需要支付任何费用。

### Q：Hermes Agent 支持哪些大语言模型？
A：目前支持 Anthropic、OpenAI、Ollama 等主流大语言模型，同时原生集成 models.dev 模型市场，后续会持续增加支持。

### Q：我可以在没有公网 IP 的环境下使用吗？
A：完全可以，Hermes Agent 支持完全本地部署，不需要公网访问。

### Q：我需要有编程基础才能使用吗？
A：基础使用不需要编程基础，按照安装指南配置后即可在终端或消息平台使用；如果需要自定义工具、技能或二次开发，则需要具备 Python 基础。
