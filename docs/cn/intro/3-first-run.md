# 3. 初次使用

> **📚 学习目标**
> 阅读本文后，你将能够：
> - 成功启动 Hermes Agent CLI 并完成第一次对话
> - 掌握 6 个常用基础命令的使用
> - 体验工具调用和技能使用的核心功能



## 启动 CLI

安装完成后，直接在终端运行：
```bash
hermes
```

你会看到欢迎界面，包含以下信息：
- 当前激活的模型
- 可用工具数量
- 可用技能数量
- 常用命令提示

**为什么要关注这些信息？**  
欢迎界面可以快速帮你确认当前的运行环境是否符合预期，避免因为模型配置错误导致使用问题。

## 第一次对话

在提示符后输入你的问题，比如：
```
> 帮我写一个 Python 快速排序的实现
```

Hermes Agent 会开始思考，你会看到可爱的动画 spinner，然后返回结果。

## 常用基础命令

### 查看帮助
```
/help
```
显示所有可用的斜杠命令和使用说明。
> 使用场景：忘记命令用法时随时查询，不需要离开终端。

---

### 切换模型
```
/model anthropic/claude-3-5-sonnet-20240620
```
切换到指定的模型。
> 使用场景：不同任务可以选择不同模型，比如写作选 Claude，代码生成选 GPT-4o。

---

### 切换皮肤
```
/skin ares
```
切换到指定的主题皮肤，内置皮肤包括 default、ares、mono、slate。
> 使用场景：根据你的偏好调整界面风格，提升使用体验。

---

### 查看会话历史
```
/history
```
查看当前会话的所有历史消息。
> 使用场景：回溯之前的对话内容，找回之前的代码或者答案。

---

### 清空会话
```
/clear
```
清空当前会话的上下文，开始新的对话。
> 使用场景：切换任务时清空上下文，避免之前的对话内容影响新任务的结果。

---

### 退出 CLI
```
/exit
```
或者使用快捷键 `Ctrl+D`。
> 使用场景：使用完成后退出程序，释放资源。

## 第一个工具调用示例

尝试让 Hermes Agent 列出当前目录的文件：
```
> 列出当前目录下的所有文件
```

首次调用工具时，会弹出权限审批提示，确认后 Hermes 会自动调用 `list_dir` 工具，返回当前目录的文件列表。你也可以在配置中设置默认信任所有工具调用，跳过审批。

## 第一个技能使用示例

内置了 `alpha-loop` 迭代开发技能，可以直接尝试：
```
> 用alpha-loop完成一个 Todo 列表应用的开发
```
技能会自动驱动多轮迭代，生成代码、验证、修复问题，直到完成任务。

## ❓ 常见问题
### Q：启动后提示 API 密钥错误怎么办？
A：运行 `hermes setup` 重新配置 API 密钥，确保密钥正确并且有足够的额度。

### Q：工具调用没有反应怎么办？
A：检查配置中是否启用了对应的工具，或者是否授予了足够的文件系统权限。

### Q：spinner 一直转没有返回结果怎么办？
A：检查网络连接是否正常，或者按 `Ctrl+C` 中断当前请求，重新发送。

### Q：可以在非交互模式下使用吗？
A：可以，使用 `hermes run "你的问题"` 命令可以直接运行单次请求，适合脚本集成。

### Q：如何查看所有可用的模型和皮肤？
A：使用 `/model list` 可以查看所有支持的模型列表，使用 `/skin list` 可以查看所有内置和已安装的自定义皮肤列表。
